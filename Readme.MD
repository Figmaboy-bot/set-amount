# Set Amount

An interactive amount/value input UI — a coded experiment in fintech and payment interface design.

---

## Overview

Setting a monetary amount sounds simple, but doing it *well* requires careful attention to interaction design. This experiment explores how to make a value input feel tactile, responsive, and trustworthy — the kind of polish you'd expect in a top-tier payments or banking app.

Part of my playground of focused UI experiments.

## Built With

- **React** — component logic and state
- **Vite** — build tooling
- **Tailwind CSS** — layout and styling
- **JavaScript** — input handling and formatting logic

## What I Was Exploring

- Currency/number input formatting that feels native
- Immediate visual feedback on value changes
- Designing for trust — how UI detail affects user confidence in financial flows
